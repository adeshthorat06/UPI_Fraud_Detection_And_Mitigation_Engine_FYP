Behavioral analysis

Features used to identify unusual user behaviour

DA
Amount Deviation

Measures how unusual the transaction amount is compared with the user's historical pattern.

DF
Frequency Deviation

Measures unusual transaction frequency compared with the user's normal activity.

DG
Graph Deviation

Identifies unusual or previously unseen recipient connections.

DT
Time-Gap Deviation

Measures unusual timing between consecutive transactions.
